# Superstore Sales Analytics

An end-to-end data analytics project analyzing retail sales data using SQL, Python, and Power BI.

## Overview
This project analyzes 10,000+ retail transactions from the Superstore dataset to uncover sales, profitability, and customer trends, and translates them into actionable business recommendations.

## Tools Used
- **SQL** (SQLite / DB Browser) — data querying and aggregation
- **Python (Pandas)** — data cleaning and preprocessing
- **Power BI** — interactive dashboard and visualization
- **Excel** — supporting analysis

## Project Files
- `queries.sql` — SQL queries for regional, product, category, and segment analysis
- `clean_data.py` — Python script for cleaning and preparing the dataset
- `superstore_cleaned.csv` — cleaned dataset used for Power BI
- `Superstore_Dashboard.pbix` — Power BI dashboard (3 pages: Sales Overview, Regional Performance, Profitability)
- `Business Insights.txt` — key findings and business recommendations

## Key Insights
1. Furniture sub-categories (Tables, Bookcases) are the biggest profitability risk — Tables alone lose ₹17,725 despite ₹206,965 in sales.
2. West region leads in both sales (₹725K) and profit (₹108K); South lags on both metrics.
3. Technology has the highest average profit per order (₹78.75), nearly 9x Furniture's (₹8.70).
4. Home Office customers get the lowest average discount (14.7%) but generate the highest average profit (₹33.82).
5. Sub-categories with discounts above ~30% tend to cluster near zero or negative profit, suggesting a need for discount caps.
